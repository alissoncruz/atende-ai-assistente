# ADR-0001 — Modular Monolith

**Status:** Accepted

## Contexto
Microserviços aumentariam a complexidade antes de existir evidência de necessidade.

## Decisão
Começar como Modular Monolith com fronteiras de domínio explícitas.

## Consequências
Deploy e debugging mais simples, com possibilidade de extração futura de módulos. Exige disciplina para manter fronteiras.
