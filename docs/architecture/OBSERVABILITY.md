# Observabilidade

Desde o MVP:
- logs estruturados;
- correlation ID;
- tenant ID quando apropriado;
- métricas;
- tracing;
- monitoramento de integrações.

Não registrar conteúdo sensível de conversas ou credenciais nos logs.

Métricas iniciais:
- mensagens recebidas/enviadas;
- latência da IA;
- erros por provedor;
- handoffs;
- leads;
- agendamentos;
- conversões.
