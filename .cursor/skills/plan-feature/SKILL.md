# Criar o plano

Não altere código de produção. Não rode a implementação. A saída é um markdown.

1. Confirme o repositório que vai receber a mudança. Plano de produto fica em `plans/` do produto. Plano deste toolkit fica em `plans/` daqui.
2. Leia só o arquivo que `knowledge/INDEX.md` indicar para essa tarefa.
3. Copie a forma de `templates/PLAN.md`.
4. Grave `plans/AAAA-MM-DD-slug.md`. O slug é curto, em minúsculas, com hífen.
5. Preencha em frases curtas: objetivo, fora de escopo, módulos, passos, como provar, riscos.
6. Deixe `Status: proposto`. Não troque para `aceito`.
7. Pare. Diga o caminho do arquivo. O código só começa noutro chat, depois que a pessoa gravar a linha `Status: aceito`.
