# Plano: CI/CD na AWS

Data: 2026-11-27
Repositório: produto
Status: proposto

## Objetivo

Um CI compila e testa o projeto, e um CD publica a API na AWS.

## Fora de escopo

Outra nuvem, banco, domínio, WhatsApp, login e página administrativa.

## Módulos

Dois arquivos de pipeline na raiz. O CI usa o Maven que já existe. O CD publica só `apps/api`. Nenhum módulo de negócio muda.

## Passos

1. `.github/workflows/ci.yml` roda `mvn verify` em cada push. O teste de domínio segue sem Spring.
2. `.github/workflows/cd-aws.yml` publica a imagem de `apps/api` no ECR. A credencial entra por OIDC e fica fora do repositório.
3. O CD roda só na branch principal.

## Como provar

Um push na branch de trabalho deixa o CI verde. Na branch principal, o ECR recebe a imagem da API e o log do pipeline não mostra segredo.

## Riscos

Segredo gravado no arquivo de pipeline. Publicar fora da branch principal gasta a conta AWS. A imagem sobe sem regra de negócio, porque a API ainda não tem caso de uso.
